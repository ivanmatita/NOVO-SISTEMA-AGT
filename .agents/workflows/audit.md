# Workflow: /audit

## Objetivo
Diagnóstico forense completo da área solicitada sem alterar código ou banco de dados.

## Passos
1. Invocar o subagente `IMATEC-AUDITOR`.
2. Analisar código fonte, schemas do Supabase, logs de erro e chamadas de API.
3. Gerar relatório forense de auditoria com Causa Raiz e Plano de Correção.
4. Apresentar relatório ao utilizador sem realizar modificações.
