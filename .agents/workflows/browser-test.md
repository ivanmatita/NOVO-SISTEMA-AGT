# Workflow: /browser-test

## Objetivo
Validação visual e funcional de ponta a ponta na interface web do IMATEC ERP.

## Passos
1. Navegar até o módulo alvo no navegador.
2. Testar abertura de formulários, preenchimento de inputs e submissão.
3. Verificar renderização de listas, tabelas e filtros de pesquisa.
4. Monitorar erros no console do navegador e respostas HTTP com status de erro (4xx/5xx).
