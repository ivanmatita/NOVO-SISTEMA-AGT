# Workflow: /regression-test

## Objetivo
Auditoria de não-regressão pós-deploy em Produção.

## Passos
1. Invocar `IMATEC-REGRESSION`.
2. Testar autenticação, faturação, POS, RH, CRM, clientes e configurações.
3. Confirmar que 100% das funcionalidades pré-existentes continuam operacionais.
4. Emitir Relatório Final de Conclusão.
