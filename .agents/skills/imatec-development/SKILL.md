# IMATEC Development Skill

Diretrizes para desenvolvimento seguro no IMATEC ERP:
- Modificar apenas os componentes, hooks e serviços diretamente relacionados à tarefa autorizada.
- Preservar tipagem TypeScript estrita e compatibilidade com React / Vite.
- Implementar tratamento defensivo de erros com fallbacks seguros.
- Nunca regredir ou remover funcionalidades pré-existentes.
